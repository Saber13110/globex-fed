Projet : Globex FedEx Intelligent Chatbot

1) PostgreSQL
   - Créer une base nommée globex_fedex (ou adapter DATABASE_URL).

2) Backend
   - cd backend
   - python -m venv .venv
   - .venv\Scripts\activate
   - pip install -r requirements.txt
   - copier .env.example vers .env et ajuster DATABASE_URL et JWT_SECRET_KEY
   - uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

3) Frontend (après génération Angular)
   - cd frontend
   - npm install
   - ng serve

4) Documentation API
   - http://127.0.0.1:8000/docs
